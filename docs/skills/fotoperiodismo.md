# Skill: fotoperiodismo

Criterios documentales, checklist de evaluación de imagen y decisión editorial de página.

## Criterio documental

Las imágenes de Rescoldo son fotoperiodismo gastronómico. No son fotografía publicitaria. La diferencia:

| Documental (sí) | Publicitaria (no) |
|------------------|-------------------|
| Plato en la mesa como quedó | Plato centrado, ángulo perfecto, garnish intacto |
| Persona trabajando, capturada en acción | Persona posando con delantal limpio |
| Espacio con uso, desgaste, vida | Espacio recién pintado, sin nadie |
| Luz natural disponible | Iluminación de estudio |
| Encuadre con contexto (manos, mesa, herramienta) | Producto aislado en fondo neutro |

## Checklist de evaluación

Antes de incluir una imagen en la web o el PDF, verificar:

- [ ] **Autenticidad** — ¿La imagen muestra algo que realmente pasó (o podría haber pasado)?
- [ ] **Especificidad** — ¿Es claramente de Rescoldo, no de cualquier restaurante?
- [ ] **Luz** — ¿Es luz natural o equivalente? ¿No hay flash evidente?
- [ ] **Contexto** — ¿Se ve dónde estamos? ¿Hay entorno, no solo sujeto aislado?
- [ ] **Imperfección** — ¿Hay algo fuera de lugar, algo real? ¿O todo es demasiado perfecto?
- [ ] **Paleta** — ¿Los tonos conviven con #FEFCF9 y los colores cálidos del sistema?
- [ ] **Resolución** — ¿Sirve para el uso previsto (hero full-bleed vs thumbnail)?

## Decisión editorial de página

### Para la web

| Uso | Requisitos |
|-----|-----------|
| Hero full-bleed | Mínimo 1200px ancho, formato landscape o portrait con centro de interés claro, soporta overlay de texto |
| Imagen de sección | 800px+, convive con texto adyacente |
| Retrato de equipo | Aspecto 3:4 o 2:3, retrato ambiental, fondo con contexto |
| Flat lay (ingrediente) | 400px+, cenital, fondo neutro natural (madera, lino), sin caption |
| Territorio | Paisaje con escala humana, formato libre |

### Para el PDF (Illustrator)

| Uso | Requisitos |
|-----|-----------|
| Full-bleed de capítulo | 220×290mm a 300dpi mínimo, sangrado incluido |
| Imagen a media página | Mínimo 200mm de ancho a 300dpi |
| Imagen de columna | Ancho de columna de texto, alta resolución |
