# Skill: nano-banana-brief

Templates de prompts visuales por categoría para generación de imágenes del proyecto Rescoldo.

## Principio general

Cada prompt visual sigue la estructura: sujeto + contexto + luz + estilo + lo que NO debe ser.

Las imágenes de Rescoldo son documentales. Nunca food styling. Nunca stock. Si la imagen podría ser de cualquier restaurante del mundo, descartarla.

## Categorías de prompt

### Plato

```
[nombre del plato], servido en [tipo de pieza de Victoria Nabel],
sobre mesa de madera de demolición.
Luz natural lateral, otoño, Buenos Aires.
Fotografía documental, sin food styling.
No: garnish decorativo, plato centrado perfecto, fondo limpio de estudio.
```

### Espacio

```
[elemento del espacio: patio / horno / mesa / galería],
casa chorizo Lanín 234, Barracas.
Luz de [momento del día], otoño 2030.
Arquitectura vernácula, paredes de ladrillo visto, columnas.
No: render 3D, espacio limpio de revista, iluminación artificial dramática.
```

### Retrato

```
[nombre de la persona], [rol],
en [ubicación dentro de la casa: cocina / patio / taller].
Retrato ambiental, sin pose, capturado en movimiento o pausa natural.
Luz natural disponible.
No: fondo neutro de estudio, pose editorial, retoque de piel.
```

### Paisaje / Territorio

```
[nombre del territorio]: [ubicación geográfica real].
[elemento específico: monte de algarrobos / arroyo del Delta / cortaderas].
Hora dorada o luz difusa.
Escala humana cuando sea posible (una persona, una herramienta, una embarcación).
No: drone cenital, HDR, paisaje turístico, sin presencia humana.
```

### Textura / Ingrediente

```
[ingrediente] en flat lay sobre [superficie: madera / lino / cerámica].
Sin estilismo. Como si alguien lo hubiera dejado ahí.
Luz natural cenital suave.
No: fondo de mármol, composición simétrica, props decorativos.
```

## Reglas transversales

1. Todas las imágenes son documentales — no generativas decorativas
2. Fotógrafo de referencia: Sebastián Ríos (crédito en el mundo diegético)
3. Paleta de la imagen debe convivir con los tokens del proyecto (#FEFCF9, tonos cálidos)
4. Sin watermarks, sin texto superpuesto en la imagen
5. Formato de entrega: WebP o AVIF, optimizado para web
