# Skill: diegetic-fiction-web

Principios diegéticos, tabla de decisiones y qué no hacer en una web de ficción.

## Qué es diegesis en este contexto

La web de Rescoldo existe dentro del mundo ficticio. No es una web sobre un proyecto de ficción. Es una web que existe en otoño de 2030, como si el restaurante fuera real.

El visitante entra a la web de un restaurante. No entra a un portfolio de design fiction.

## Principios

1. **Todo elemento de la web debe funcionar dentro del mundo ficticio.** Si no tiene función diegética, no va.
2. **La ficción no se anuncia.** El disclaimer va en el footer, en tipografía pequeña, separado por una línea. Nunca al principio.
3. **Los datos burocráticos son parte del diseño.** CUIT, dirección, horarios de temporada, precios en pesos — estos detalles mundanos hacen que el mundo sea creíble.
4. **El tiempo es 2030.** Todas las fechas, precios y referencias temporales corresponden a otoño de 2030.
5. **El clima es real, la fecha es ficticia.** El weather widget muestra la temperatura real de Barracas hoy, pero la fecha dice 2030.

## Tabla de decisiones

| Pregunta | Respuesta |
|----------|-----------|
| ¿Agrego un link a Instagram? | No. Instagram de ficción no existe. |
| ¿Agrego reservas online? | No. No es transaccional. Lista de espera solamente. |
| ¿Pongo "Este es un proyecto de ficción" arriba? | No. Va en el footer, chico. |
| ¿Uso precios reales de 2026? | No. Precios plausibles de 2030. |
| ¿Agrego Google Maps? | No. La dirección es ficticia, no lleva a ningún lado. |
| ¿Agrego testimonios de clientes? | No. Los "clientes" no existen. La cita de prensa diegética (Lento) sí. |
| ¿Agrego un blog? | No. El journal ES el contenido. No hay meta-contenido. |
| ¿Agrego "Sobre nosotros"? | No. La voz de Julián en primera persona ya cuenta todo. |
| ¿Pongo copyright 2026? | No. © 2030 Julián Arce. |
| ¿Agrego analytics visible? | No. Cookie banners rompen la diegesis. |
| ¿La 404 dice "Página no encontrada"? | No. "Esta sección de la temporada está cerrada." |

## Universo compartido

La web de Rescoldo coexiste con el proyecto Mercado San Telmo 2030 (futures-in-maps.com/san-telmo, de Nicolás Bronzina + Near Future Laboratory). Ambos existen en el mismo año ficticio.

## Qué NO hacer

- No romper la cuarta pared antes del footer
- No usar lenguaje de producto digital (explorar, descubrir, experiencia única)
- No agregar funcionalidades que un restaurante real de 10 cubiertos no tendría
- No explicar que es ficción excepto en el disclaimer del footer
- No mezclar fechas reales (2026) con fechas diegéticas (2030)
- No crear redes sociales ficticias
- No agregar elementos de e-commerce
